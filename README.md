## 机房在美国，国内访问是什么量级

RackNerd 的机房全在美国，公开资料里没有针对这些特价套餐的统一测试 IP 或 Looking Glass，所以国内延迟只能按"美国机房"的公开量级估：

- 洛杉矶普通国际线路，国内 ping 通常 180 ms 起步，晚高峰还会抖；
- 同样在洛杉矶、走 CN2 GIA 这类优化线路的机器，公开测评里上海电信晚高峰能到 130-140 ms，北京联通约 150 ms，广州移动 160 ms 以内。

这 40-60 ms 的差距落到体验上，就是首屏快半秒到一秒。RackNerd 的定位是低价美国 KVM，官方页面强调的是 1 Gbps 端口和机房选择，没有提优化线路，按第一档预期比较合理。做中文博客、读者主要在国内，这一点要提前想清楚：能接受就买，接受不了就别指望它变成香港机房。

带宽这块反而不用担心。它给的是 1 Gbps 端口，瓶颈在月流量不在带宽。3 TB 按单页 100 KB 估，是 3000 万次页面访问的量级；就算你的页面带图，平均 1 MB 一页，也有 300 万次。个人博客离这个数字很远。

顺便记一下换算关系，方便你判断图片站够不够：1 Mbps 约等于 128 KB/s，3 Mbps 约等于 375 KB/s。这是国内轻量服务器常见的带宽口径，RackNerd 不在这个量级上，但如果你以后换机器会用得上。

## 买完怎么上线：从重装系统到 HTTPS

RackNerd 用的是自家的 ctrl 控制面板，不是 SolusVM。开机后在里面重装系统、开 HTML5 VNC 控制台、用 Network Firewall 设入站规则、重置 root 密码，都能自己搞定。系统可选 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu，需要自定义 ISO 开工单。ctrl 里还有一键应用，CyberPanel、CloudPanel 这类面板可以直接装，WordPress 跑在上面；想用宝塔也完全可以，Root 权限都给你。

一条稳妥的路子：

1. ctrl 里重装成 Debian 或 Ubuntu，记下 IP 和 root 密码。
2. SSH 登录，跑宝塔安装脚本。CentOS 用 `install_6.0.sh`，Ubuntu/Debian 用 `install-ubuntu_6.0.sh`，两条命令在宝塔官网首页都能复制。
3. 到 ctrl 的 Network Firewall 放行 8888 端口，浏览器打开 `http://你的IP:8888` 进面板，套件选 LNMP。
4. 宝塔「软件商店 → 一键部署」里选 WordPress，填站点信息，等它跑完。
5. 域名 DNS 加一条 A 记录指向这个 IP。机器在美国，不需要 ICP 备案，解析生效就能访问。
6. 宝塔「网站 → 对应站点 → SSL」申请 Let's Encrypt 免费证书，开强制 HTTPS。
7. 最后一步最容易漏：WordPress 后台「设置 → 固定链接」选 `/%post_id%.html`，回宝塔「网站 → 伪静态」选 WordPress。不做这步，文章页会 404。

主题挑 Astra、GeneratePress 这类轻量的，插件按需装 Yoast SEO、Wordfence、UpdraftPlus 三个就够，缓存插件用 WP Super Cache 起步。1 GB 内存的机器上，插件每多一个都是负担。

## 这几种情况，RackNerd 不合适

说清楚边界比硬推有用。

**读者主要在国内、要求首屏一秒内打开，并且能接受备案。** 选大陆机房的轻量应用服务器更合适。腾讯云轻量的 4核4G3M 套餐，个人新用户秒杀价 38 元/年起（配置口径以官方活动页为准），代价是大陆地域绑定域名必须完成 ICP 备案，备案通常要 20 天以上，快则两周慢则一个月。

**预算在 100 元人民币级，又想要香港机房免备案。** 野草云 2012 年成立，香港 AMD 1核1G / 10 GB NVMe 的常规款 88 元/年，电信实测 ping 67 ms，这个价位放在香港机房里确实低。它的首年 5 折、8 折属于促销价，续费恢复原价，长期持有要把第二年按原价算进去。

**要香港最低延迟、预算能到每月 $89.99。** 搬瓦工的香港 CN2 GIA，2 GB / 4 核 / 40 GB SSD / 500 GB 月流量，$89.99/月或 $899.99/年。这个价位买的不是配置，是延迟和稳定性。

**完全不想碰 Linux。** RackNerd 是无管理 KVM，ctrl 的一键应用能省掉装面板的功夫，但系统更新、备份、故障排查还是你自己的事。要一键镜像开箱即用，就回大陆云厂商那边。
